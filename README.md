# Ai365 Demo

Ai365 화면과 FastAPI 백엔드를 연결한 데모입니다. Agentic Ai365에서 폴더를 열어 작업을 요청하고, 위젯 에이전트에서 대화로 홈 화면의 KPI와 차트를 만들 수 있습니다.

## 실행

Python 3.12 환경에서 저장소 루트에서 실행합니다.

```shell
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

브라우저에서 [localhost:8000](http://127.0.0.1:8000)을 엽니다. 외부 모델이 필요한 요청을 테스트할 때는 본인의 키를 로컬 `.env`에서 설정합니다. 화면과 기본 샘플 데이터는 로컬 데모에서 확인할 수 있습니다.

## Agentic Ai365

로컬이나 브라우저에서 선택한 폴더를 세션에 연결합니다. 에이전트가 파일을 찾아 읽고, 필요한 편집을 제안합니다. 작업에 따라 서브에이전트에 탐색이나 검토를 나누고, 실행 중인 도구와 결과를 화면에 표시합니다. 코드 실행, Git 변경 이력, 승인 흐름은 지원하는 세션에서 확인할 수 있습니다.

제품 설계에서는 Microsoft 365의 SharePoint 폴더를 작업공간으로 쓰는 방식을 검토했습니다. 이 저장소의 데모는 로컬 및 브라우저 폴더를 사용합니다.

## 위젯 에이전트

홈에서 위젯 에이전트를 열고 원하는 숫자나 차트를 요청합니다. 필요한 경우 어떤 데이터를 연결할지 되묻고, 사내 데이터, 문서 또는 웹에서 가져온 정보를 미리보기로 보여줍니다. 완성한 위젯은 홈에 배치하고 대화에서 다시 수정할 수 있습니다.

Agentic과 위젯의 서버 코드는 `app/`에, 화면 코드는 `frontend/`와 `static/`에 있습니다.
